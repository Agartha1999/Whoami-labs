En este laboratorio aprendimos a realizar un proceso básico de pentesting web siguiendo una metodología estructurada. 
Realización de un proceso básico de pentesting web siguiendo una metodología estructurada.
	-Reconocimiento inicial del sistema utilizando Nmap para identificar servicios y puertos abiertos.
	-Enumeración de directorios y rutas ocultas mediante Gobuster en la aplicación web.
	-Identificación de una vulnerabilidad de Command Injection que permitió ejecutar comandos en el sistema operativo desde la web.
	-Obtención de acceso al sistema a través de la explotación de dicha vulnerabilidad.
	-Escalada de privilegios aprovechando una mala configuración de sudo (comando find).
	-Obtención de acceso como usuario root.
	-Recuperación de las flags del sistema.
	Refuerzo de conceptos clave:
		-Reconocimiento de sistemas
		-Enumeración de servicios y rutas
		-Explotación de vulnerabilidades web
		-Escalada de privilegios en entornos Linux
