En este laboratorio aprendimos a realizar un proceso básico de pentesting web siguiendo una metodología estructurada. Primero realizamos reconocimiento con Nmap para identificar servicios abiertos. Luego hicimos enumeración con Gobuster para descubrir rutas ocultas en la aplicación web. Se identificó una vulnerabilidad de Command Injection, la cual permitió ejecutar comandos en el sistema operativo desde la web. A través de esta vulnerabilidad se obtuvo acceso al usuario del sistema y posteriormente se realizó una escalada de privilegios mediante una mala configuración de sudo (find). Finalmente se obtuvo acceso como root y se recuperaron las flags del sistema. Este laboratorio reforzó conceptos clave como reconocimiento, enumeración, explotación de vulnerabilidades y escalada de privilegios en entornos Linux.
